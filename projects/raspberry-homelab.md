## 🚀 Selected Projects

### Raspberry Pi HomeLab

A personal infrastructure project focused on building a self-hosted
engineering environment using Raspberry Pi 5.

The project combines software development, QA infrastructure,
networking, automation and DevOps practices.

**Technologies:**

- Raspberry Pi 5
- Linux
- Docker
- GitHub
- Python
- Telegram Bots
- Grafana
- Prometheus
- VPN
- Networking
- CI/CD
- Infrastructure as Code

**Key goals:**

- Host personal services and Telegram bots
- Build a self-hosted development environment
- Configure Raspberry Pi as a network/VPN gateway
- Implement monitoring with Prometheus and Grafana
- Automate deployment using Docker
- Experiment with local AI/LLM infrastructure
- Build a foundation for a personal home automation system
